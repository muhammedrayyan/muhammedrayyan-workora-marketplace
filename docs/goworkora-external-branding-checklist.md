# GoWorkora external branding checklist

Repository branding is complete only for assets and copy controlled by this
codebase. Before production release, manually confirm:

- Supabase project display names are intentionally retained or renamed without
  changing project references.
- Supabase Auth email subjects, HTML templates, sender display name, and sender
  address show GoWorkora.
- Resend domain and sender identity show GoWorkora and remain verified.
- Stripe Connect platform profile, public business name, branding, support
  details, statement descriptors, receipts, and hosted onboarding use approved
  GoWorkora wording.
- GitHub repository description, Pages title, deployment environment, and
  custom-domain metadata use GoWorkora where appropriate.
- Search-engine profiles, social profiles, booking links, and customer-support
  tools use only real configured GoWorkora destinations.
- Legal counsel has reviewed the draft Terms, Privacy, Cookie, payment, and
  dispute wording under the GoWorkora name.

Do not rename database objects, API keys, webhook destinations, storage buckets,
or environment-variable names merely to satisfy visual branding.
